# Rajesh Kumar — Portfolio

Full stack developer portfolio built with React, Vite, and the ThreeUI **SylvaHero** (Living Green) scene.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Build

```bash
npm run build
npm run preview
```
